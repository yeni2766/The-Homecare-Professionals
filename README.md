# The Homecare Professionals Website

A professional, responsive recruitment-focused website built for The Homecare Professionals to help users browse healthcare job opportunities and access key company information easily.

## Overview

The Homecare Professionals website was designed and developed to create a clean, user-friendly online presence for a healthcare recruitment/service brand. The project focused on improving accessibility, mobile responsiveness, navigation, and the overall candidate journey from job discovery to enquiry.

## Features

- Responsive website design for desktop, tablet, and mobile devices
- Clean, professional frontend interface
- Recruitment-focused user journey
- Clear navigation and content structure
- Healthcare job information presented in an accessible format
- User-friendly layout built to support job seekers and service users

## Tech Stack

- WordPress
- Elementor
- HTML5
- CSS3
- Responsive Design
- UI/UX Design

## Key Contributions

- Developed a professional WordPress website using Elementor
- Created a clean frontend interface for healthcare job seekers
- Designed a recruitment-focused user journey across key actions: browsing roles, reviewing requirements, and making contact
- Built mobile-responsive layouts across recruitment and service pages
- Improved visual hierarchy, navigation, and content flow to make healthcare job information easier to access

## Project Outcome

The final website provided The Homecare Professionals with a modern, responsive, and accessible digital presence, helping candidates browse healthcare opportunities more clearly and efficiently across devices.
